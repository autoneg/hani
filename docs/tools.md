# Tools

HANI provides several tools to help you analyze and understand the negotiation. Tools are available in the sidebar during negotiations.

## Analysis Tools

### Preferences View

Displays your utility function and preferences for the current negotiation.

**Features:**

- Shows the weight of each issue
- Displays value mappings for each issue
- Shows your reservation value (disagreement outcome utility)

**Usage:**

Use this tool to understand:

- Which issues matter most to you
- How different values affect your utility
- What outcomes to avoid (below reservation value)

### Utility Plot

Visualizes utility over time throughout the negotiation.

**Features:**

- Plots your utility for each offer
- Shows both your offers and partner's offers
- Highlights accepted/rejected offers

**Usage:**

Track how the negotiation is progressing:

- Are utilities trending upward or downward?
- How do your offers compare to partner's offers?
- When was the best offer made?

### Outcome Plot

Shows where offers fall in the outcome space.

**Features:**

- 2D visualization of the outcome space
- Plots all offers from both parties
- Shows the Pareto frontier (if available)

**Usage:**

Understand the negotiation dynamics:

- Are offers moving toward agreement?
- How far are offers from optimal outcomes?
- Is there room for mutual improvement?

### History

Displays the complete negotiation history.

**Features:**

- All offers with timestamps
- Text messages exchanged
- Acceptance/rejection status

**Usage:**

Review what has happened:

- What offers have been made?
- What did the partner say?
- How has the negotiation evolved?

### Scenario Info

Shows information about the current scenario.

**Features:**

- Scenario name and description
- Issue descriptions
- Hints and tips (if available)

**Usage:**

Understand the negotiation context:

- What are the issues about?
- What's the backstory?
- Any strategic hints?

## How to Use Tools

1. **Open a tool:** Click on the tool name in the sidebar
2. **View information:** Tools automatically update during negotiation
3. **Close a tool:** Click the close button or select another tool

## Tool Availability

| Tool | Available When | Admin Only |
|------|----------------|------------|
| Preferences | Always | No |
| Utility Plot | During negotiation | No |
| Outcome Plot | During negotiation | No |
| History | During negotiation | No |
| Scenario Info | After scenario loaded | No |
| Response Generator | During negotiation | No |
| Random Selector | During negotiation | Yes |
| Utility-based Selector | During negotiation | No |

!!! tip "Using Multiple Tools"
    You can switch between tools at any time. The negotiation state is preserved, and tools update automatically when you return to them.
